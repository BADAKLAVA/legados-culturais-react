# Legados Culturais — React

Portal de recursos escritos e visuais sobre Patrimônio Cultural
## Site
https://legados-culturais-react.vercel.app/
## Rodar localmente

```bash
npm install
npm run dev
```

Depois, abra a URL mostrada pelo Vite.

Rotas visuais disponíveis:
- `/` — página inicial
- `/cadastro` — cadastro
- `/login` — login
